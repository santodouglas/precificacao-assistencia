# Preço de Telas (consulta da loja)
Site estático. `index.html` lê `dados.json` (compras de tela, cotações do gerente e regras de preço).
Atualizar: exportar o banco do app e rodar `node gen.js <pasta-do-banco>`; fazer push (a publicação é automática).
Cotações cadastradas no site ficam só no aparelho de quem cadastrou.
